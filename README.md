# Chess Game (Unity)

A complete Unity chess game

## 🧩 Features
- Full chess logic (including check, checkmate, and stalemate)
- Simple, responsive UI
- Sound effects and SFX toggle
## Controls 
- Mouse1: Select/Escape
- Escape: Menu
